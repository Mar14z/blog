2025.03–06 嵌入式 AI

海胆检测与移动端部署

基于 YOLOv11n 在海胆数据集上做改进：Backbone 常规卷积替换为 IDC 模块，增强低分辨率图像和小目标的特征表达；损失函数由 CIoU 换成 SIoU，提升检测框回归精度。mAP@0.5 从 90.95% 提升到 92.27%，参数量 2.591M、GFLOPs 6.47；为部署到 Android，对模型做剪枝与 FP32→INT8 量化，体积压缩 35%。应用支持拍照与相册输入、框选可视化和数量统计，联调测试识别准确率 90% 以上。

YOLOv11 IDC SIoU INT8 量化 Android

2024.09–11 低功耗 IoT

野生动物检测识别系统

独立完成 ESP32 端程序、服务端与 Web 前端。设备用深度睡眠配合 Rd-03 传感器中断唤醒，压低平均功耗并缩短冷启动；按网络条件双协议上传，WiFi 下走 HTTP 传图、4G 下用 MQTT 传状态。服务端用 PHP 接收并按时间归档，Nginx 反向代理，前端提供基于 YOLOv8 的识别界面。
